# Cheat.Guard v1.9.20

Fixes the visible PowerShell console windows that appeared instead of (or
alongside) the app.

- **The elevated network helper ran with `-WindowStyle Normal`, so a PowerShell
  console stayed open on screen for the entire exam session.** It is now
  hidden, as are the elevation relay that waits behind the UAC prompt when the
  app starts, the elevated log-deletion console, and the app-start liveness
  probe.
- **The fail-safe scheduled task (runs every 3 minutes and at logon) had no
  window style**, so a PowerShell console flashed on screen every few minutes.
  Both task registrations (app start and helper) now run hidden, and the task
  script path is properly quoted.
