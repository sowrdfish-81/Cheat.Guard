# CheatGuard Central v1.9.23

## Invigilator screen

- The **Back** button no longer stops a running monitor. Previously leaving
  the monitor screen silently stopped the session, and returning showed a new
  random exam code while students were still joined with the old one. Now the
  invigilator must press **Stop** first; the warning explains why.
- The exam code is shorter: 6 digits (was 10). Codes accept 3-6 letters or
  numbers on both the monitor and the student setup card.

## Removed

- The "Export student truststore" button and the "Import central truststore"
  setting are gone - student PCs pair automatically via the monitor's beacon,
  so the manual file workflow had no remaining purpose.
