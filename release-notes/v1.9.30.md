# CheatGuard Central v1.9.30

## Fixes

- Faster normal exam-session shutdown and network restoration.
- Reduced per-path ACL cleanup timeout from 30 seconds to 8 seconds.
- Removed the redundant per-path ACL verification pass during normal close, with a bounded retry for failed cleanup.
- Preserved the existing stale-session recovery path and Central Monitor behavior.

## Installer

Download `CheatGuardCentral-Setup.exe` and install it over the previous version.
