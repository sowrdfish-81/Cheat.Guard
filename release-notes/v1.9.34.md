# Cheat.Guard v1.9.34

## Fixes

- Rebuilds a missing session `.dat` log from the in-memory audit rows before sealing.
- Invigilator monitor firewall rule now uses an elevated UAC flow instead of silently failing.
- Discord firewall rules refresh during the exam for newly installed versioned executables.
- Includes Discord `Update.exe` allowlisting, central LAN fallback discovery, password re-key handling and faster session close.

## Installer

Install `CheatGuardCentral-Setup.exe` on all invigilator and student PCs.
