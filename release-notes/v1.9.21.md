# CheatGuard Central v1.9.21

Fixes the PowerShell console windows that appeared instead of the app and
restores the permanent fail-safe net.

- The elevated network helper ran with a visible console for the whole
  session; the app-start elevation relay, the elevated log-deletion console
  and the fail-safe scheduled task (every 3 minutes) were visible too. All
  PowerShell surfaces are hidden now.
- The app-start fail-safe registration could abort on a helper-file copy
  error (leaving the machine with no recovery net); it now registers the
  task even when the copy fails, updates the helper via a staged move, and
  logs the real error class. Session start no longer aborts when an
  identical/updatable helper cannot be replaced but an existing copy exists.
