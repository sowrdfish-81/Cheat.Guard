# Cheat.Guard v1.9.31

## Fixes

- Improved invigilator discovery by sending UDP beacons through each active LAN/Wi-Fi interface.
- Discord `Update.exe`, versioned Discord folders, crashpad and helper executables are trusted automatically inside Discord's install roots.
- Session-log sealing now retries transient Windows Defender/indexer file locks and removes partial vault output before retrying.
- Retained faster normal session close and network restoration from v1.9.30.

## Installer

Install `Cheat.Guard-Setup.exe` on the invigilator and student PCs.
