# Cheat.Guard v1.9.32

## Fixes

- Discord `Update.exe` is always present in the backend allowlist.
- Discord versioned install folders, child executables, crashpad helpers and related domains are allowed automatically.
- Invigilator discovery now uses per-interface UDP beacons and a same-subnet TCP monitor fallback when Wi-Fi drops broadcasts.
- Existing session-log seal retry and fast close fixes are included.

## Installer

Install `Cheat.Guard-Setup.exe` on both invigilator and student PCs.
