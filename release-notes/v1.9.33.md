# CheatGuard Central v1.9.33

## Fixes

- Password-change re-encryption now uses the elevated delete path for protected vault/signature pairs instead of failing with Windows `Access is denied`.
- Discord `Update.exe` and versioned Discord executables remain automatically allowed.
- Invigilator central-monitor discovery retains per-interface UDP and same-subnet TCP fallback.

## Installer

Install `CheatGuardCentral-Setup.exe` on the administrator/invigilator and student PCs.
