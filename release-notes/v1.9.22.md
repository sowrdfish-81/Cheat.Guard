# CheatGuard Central v1.9.22

## Central monitor on changing networks (hotspot fix)

- The monitor broadcasts a UDP beacon (port 47822) every two seconds while it
  runs. A student PC that leaves the invigilator-IP field empty finds the
  monitor automatically and connects back to the address the beacon actually
  came from, so a hotspot/DHCP address change no longer breaks the join. A
  manually typed IP always wins.
- The monitor screen lists every address students could use (the gateway
  adapter first) instead of only the default-gateway IP - on a hotspot setup
  that adapter has no gateway and the old screen showed an unreachable IP.
- When the network changes, the monitor certificate is regenerated
  automatically with the new addresses (the old identity is kept as an
  orphaned backup) instead of silently failing every student connection.

## Automatic student pairing (no file copying)

- The beacon carries the monitor certificate's SHA-256 fingerprint. A student
  PC with no truststore yet - or one holding a just-rotated certificate -
  captures the presented certificate, pins it only after matching the beacon
  fingerprint, and reconnects with full TLS validation. No truststore file
  has to be copied to student PCs any more.
- Manual truststore export/import remains on both screens as an optional
  offline fallback for networks that block the beacon (for example
  AP-isolated campus WiFi).

## Student-side visibility

- Every distinct central-link failure now names its reason on the student's
  live screen and in the sealed log: no monitor beacon heard, certificate
  does not match its beacon, certificate does not cover the IP, wrong exam
  code, or unreachable - instead of a single generic row.
- A successful join reports "Connected to the invigilator's monitor" once, so
  a working link is distinguishable from a silent one.

## Security

- The firewall helper now also allows the inbound UDP beacon port on student
  PCs while the exam lockdown is active.
- The exam-code model is unchanged: one unique code per exam/class, and the
  HMAC challenge-response proof stays mandatory on the encrypted channel.
