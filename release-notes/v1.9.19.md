# CheatGuard Central v1.9.19

Fixes the live-session failures reported on machines with cloud-synced user
folders (OneDrive / Google Drive): exam sessions could not start, the file
wall never armed, and restores could hang.

## Session start (the main fix)

- **The elevated helper hung applying the file wall and the session never
  started.** Setting the inheritable deny on `Documents` (OneDrive-integrated)
  took 79+ seconds in testing - NTFS pushes the ACE through thousands of cloud
  placeholder children - and could effectively block forever. Every takeown /
  icacls call now runs with a hard timeout and its stderr isolated, so a slow
  or unsupported cloud filesystem (Google Drive rejects the deny, exit 87)
  skips that one path instead of freezing the whole arm sequence.
- The helper now logs the locked-path count and every skipped path, so the
  step-by-step log shows exactly where a file wall is partial.
- The app waits up to 5 minutes (was 2.5) for the helper's READY marker.
- The fail-safe task no longer misses a live helper whose elevated command
  line it cannot read - it previously could race a live session's restore.

- All of v1.9.18's second-pass fixes (the previous release shipped before
