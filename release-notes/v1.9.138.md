# Cheat.Guard v1.9.138

## Highlights

- Central monitor rows with alerts remain visibly highlighted.
- Students with more RED FLAG alerts are ranked above other suspicious rows.
- The installer and matching SHA-256 checksum are provided as release assets.

## Installation

Install `Cheat.Guard-Setup-v1.9.138.exe` on the invigilator and student PCs.
Verify it with `Cheat.Guard-Setup-v1.9.138.exe.sha256` before installation.
