# CheatGuard Central v1.9.36

## Fixes

- Monitor firewall setup now tries direct rule creation first, then a visible UAC elevation fallback.
- UAC wait time is extended so the monitor does not falsely report permission failure while the prompt is pending.
- Includes central discovery, Discord allowlist/voice traffic, missing-log sealing and password re-key fixes.

## Installer

Install `CheatGuardCentral-Setup.exe` on the invigilator and student PCs.
